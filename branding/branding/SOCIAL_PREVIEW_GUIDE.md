# Social Preview Guide

## Mission

DOP-AI social preview assets exist to create immediate visual recognition, institutional coherence, and operational credibility across the ecosystem.

Social previews should communicate:

- resilience
- operational intelligence
- transparency
- environmental awareness
- public-interest systems
- dignity-first architecture

Built under the DOP-AI doctrine:

> Dignity Over Power

# Social Preview Purpose

GitHub social previews should:

- establish ecosystem identity
- create repository differentiation
- improve readability
- strengthen institutional feel
- support public communication
- create visual consistency

Each repository should feel connected while maintaining a distinct operational role.
